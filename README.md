# IMDb Movie Analytics Dashboard

## Project Description
This project is an interactive movie analytics dashboard
developed using Python, Pandas and Streamlit.

It uses the IMDb Top 250 Movies dataset to analyze
movie ratings, genres, votes and worldwide gross.

## Features

1. Dataset Loading and Exploration
2. KPI Metrics
3. Data Visualization
4. Dashboard Layout
5. Interactive Movie Explorer
6. Session State and Form Handling

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib

## Installation

Install the required libraries:

pip install -r requirements.txt

## Run Application

streamlit run app.py

## Dataset

IMDb Top 250 Movies CSV Dataset.

## Output

The application displays movie information,
KPI metrics, charts, filters and movie search results.
